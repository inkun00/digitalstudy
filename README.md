# 사이버 마음 상담소

초등학생이 사이버폭력 피해 친구의 이야기를 듣고 안전한 응대를 연습하는 교육용 챗봇입니다. 사용자의 **각 답변**을 피해 상황과 이전 대화에 비추어 평가하고, 그 결과에 따라 화면의 마음 안정도 추정치가 변합니다. 이 점수는 실제 정신 건강 진단이나 회복의 증명이 아닙니다.

## 실행

```bash
npm install
npm run dev
```

`http://localhost:3000`에서 열 수 있습니다. `npm test`, `npm run lint`, `npm run build`로 점검합니다.

피해 친구의 답장에는 NAVER Cloud CLOVA Studio의 HyperCLOVA X(HCX-005)를 사용합니다. [CLOVA Studio 콘솔에서 API 키를 발급](https://guide.ncloud-docs.com/docs/en/clovastudio-apikey)받고 `.env.local.example`을 참고해 `.env.local`에 `CLOVA_STUDIO_API_KEY`를 설정한 뒤 서버를 다시 시작하세요. 키는 서버에서만 읽으며 브라우저로 보내지 않습니다. 키가 없거나 API가 실패하면 정해진 문장으로 대체하지 않고 오류를 표시하며 입력 문장을 복구합니다.

첫 화면에서 이메일로 로그인하거나 회원가입합니다. 회원가입할 때 상담자의 이름·성별·나이를 입력하며, 로그인 후에는 하단 **마이** 메뉴에서 프로필을 수정할 수 있습니다. 친구를 선택하면 대화방이 열립니다. 프로필과 친구별 대화는 Firebase Cloud Firestore에 저장됩니다. 기존 익명 계정에서 회원가입하면 같은 계정에 이메일을 연결해 대화와 하트 기록을 이어갑니다. 이전 `sessionStorage` 대화도 첫 연결 때 가져옵니다. 입력 정보는 피해 친구 응답의 호칭에 사용합니다. 도우미에서는 선택한 친구의 피해 경위와 예방·대처 방법을 볼 수 있습니다. 도우미를 열면 넓은 화면에서는 채팅 오른쪽에 독립 패널이, 좁은 화면에서는 채팅 아래에 함께 보이는 패널이 나타납니다.

## Firebase 저장

Firebase 웹 앱의 설정값을 `.env.local`에 `NEXT_PUBLIC_FIREBASE_API_KEY`, `NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN`, `NEXT_PUBLIC_FIREBASE_PROJECT_ID`, `NEXT_PUBLIC_FIREBASE_APP_ID`로 입력합니다. Firebase 콘솔에서 **Authentication → 익명 및 이메일/비밀번호 로그인**을 활성화하고 **Cloud Firestore**를 만든 뒤 `firestore.rules`를 게시해야 합니다. 앱은 사용자별로 `users/{uid}/state/profile`에 프로필을, `users/{uid}/state/wallet`에 하트·구매·가방 내역을, `users/{uid}/chats/{scenarioId}`에 피해 친구별 대화를 저장합니다. 첫 연결 때 브라우저에 남아 있는 기록을 가져오며, Firebase에서 기록을 읽어 화면을 준비한 뒤 새 변경 사항을 동기화합니다. 네트워크 오류가 나면 로컬 기록을 보관하고 화면에 다시 연결 버튼을 표시합니다. 이메일 계정으로 로그인하면 다른 기기에서도 같은 기록을 볼 수 있습니다. 계정을 바꿀 때는 이전 계정의 로컬 기록을 지워 서로 섞이지 않게 합니다.

## 하트 포인트와 상점

응대로 마음 안정도가 실제로 상승한 점수만큼 하트 포인트가 적립됩니다. 점수가 내려가거나 그대로이면 적립되지 않습니다. `/shop`의 가상 상점에는 사이버폭력 피해 친구를 위한 오리지널 판타지 아이템 100종(5가지 주제, 각 20종)과 채팅방 배경 6종이 있습니다. 각 아이템에는 고유한 소개, 회복 효과, 이미지가 있습니다. 상품 정보는 `src/lib/fantasyItems.js`, 개별 이미지 파일은 `public/items/fantasy-001.webp`부터 `fantasy-100.webp`에 있습니다. 구매한 마법 아이템은 대화방의 가방 버튼에서 친구에게 선물할 수 있습니다. 아이템의 기본 안정도 상승값은 10~13점이지만, 선물 속성이 친구의 피해 유형과 맞을 때만 적용됩니다. 친구별 아이템 보너스는 최대 40점이며, 아이템 사용으로 오른 점수에는 하트 포인트를 지급하지 않습니다. 아이템 효과는 교육용 시뮬레이션 수치로 실제 심리 치료나 안전 조치를 대신하지 않습니다. 포인트·가방·배경 구매 내역은 브라우저의 `localStorage`와 Firebase 연결 시 Firestore에 저장됩니다. 실제 결제는 없습니다.

대화 평가 리포트에서 예시 가사를 생성하거나 다시 생성할 때마다 하트 100포인트가 소모됩니다. 잔액이 부족하면 생성할 수 없으며, 생성 요청이 실패하면 차감액을 돌려줍니다.

## 배포 설정

이 프로젝트는 Next.js 서버 API(`/api/chat`, `/api/coach`, `/api/report`, `/api/lyrics`)를 사용하므로 정적 GitHub Pages만으로는 실행할 수 없습니다. Node.js를 지원하는 호스팅에서 이 저장소를 연결하고, `.env.local.example`에 나열된 환경 변수를 호스팅 설정에 등록하세요. 실제 `.env.local`과 API 키는 Git에 올리지 않습니다.

## 평가 흐름

1. 학생이 피해 친구에게 답합니다.
2. `/api/coach`가 HyperCLOVA X로 피해 상황과 최근 대화를 함께 읽고, 직전 피해자의 말에 대한 사용자의 답변을 평가합니다. 안정도 변화는 한 번에 -12~+16점으로 제한합니다. 짧은 수락이나 동행 약속도 앞선 요청과 연결해 평가합니다.
3. `/api/chat`이 피해 상황, 성격, 상담자 정보, 최근 대화와 평가 결과를 HyperCLOVA X에 전달해 피해 친구의 다음 답장을 생성합니다.
4. `/api/report`가 실제 대화와 누적 점수를 바탕으로 피드백과 노랫말 활동 자료를 만듭니다.

각 답변 아래에 점수 변화와 근거가 나타납니다. 안정도는 25점에서 시작하며 0~100점 범위를 벗어나지 않습니다. 피해 친구가 실제로 안전한지와 필요한 보호 조치는 신뢰할 수 있는 어른이 확인해야 합니다.

피해 친구는 자신의 상황에 무관한 화제가 나오면 혼란스러워하며 다시 이야기를 들어 달라고 요청합니다. 경청이나 도움을 거부하는 말에는 서운함을 드러냅니다. 이런 답변은 응대 평가에도 반영됩니다.

피해 친구의 대화와 응대 평가는 생성형 AI를 사용하며 실제 피해자의 반응이나 임상적 회복 정도를 보장하지 않습니다. 점수와 하트 포인트는 교육용 시뮬레이션 수치입니다. 모델 평가가 실패하면 임의의 규칙 점수를 부여하지 않고 오류와 함께 입력 문장을 복구합니다.
